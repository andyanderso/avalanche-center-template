# avalanche_social_meta

Generic replacement for `gulmarg_social_meta` / `argentina_social_meta`.

Token provider (`[node:overall-danger-icon]`, `[node:obs-image-for-social-media]`)
feeding Metatag's per-content-type config. The logo fallback filename
(`gac_logo_white.jpg` vs `ciap-logo-2.png`) is no longer hardcoded — it reads
`avalanche_center.settings.social_fallback_logo`, set per center via the
setup form / admin settings.

See `AVALANCHE_CENTER_DISTRIBUTION_PLAN.md` §7.
