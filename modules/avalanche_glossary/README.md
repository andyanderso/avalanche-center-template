# avalanche_glossary

Generic replacement for `gulmarg_glossary` / `argentina_glossary`.

Renders the avalanche terms glossary from the `avalanche_terms` taxonomy
vocabulary. Path stays the single English machine name `/avalanche-terms`
(Argentina's `terminos-avalanchas` alias was dropped) — Spanish is a
translation of the page title/strings, not a separate path.

See `AVALANCHE_CENTER_DISTRIBUTION_PLAN.md` §3, §13.
